# 2026淘金币双11，刷金币脚本

通过 **Android 手机 + USB / 无线 ADB** 操作淘宝 2026 双11活动页面，支持任务浏览、搜索后浏览、支付宝相关页面短停和赛车升级。

本项目参考并改写自 [Kimger/coin11-tb](https://github.com/Kimger/coin11-tb) 和其上游 [czl0325/coin11-tb](https://github.com/czl0325/coin11-tb)。感谢两个仓库的作者与贡献者提供页面适配、任务识别和升级逻辑的基础。来源及改动见 [SOURCES.md](SOURCES.md)，沿用 [Apache License 2.0](LICENSE)。

任务进度与奖励由淘宝判定。遇到验证会停止，需手动处理；本项目不提供验证码破解或免风控承诺。

## 功能

| 菜单 | 功能 |
| --- | --- |
| 1 | 预览当前可识别的任务，不点击任务按钮 |
| 2 | 自动扫描 → 执行一项 → 返回 → 重新扫描，直到没有新任务或达到上限 |
| 3 | 消耗活动能量升级赛车，关闭已识别的奖励或款式弹窗后继续 |
| 0 | 退出 |

- **浏览**：确认进入浏览页后连续下滑，按任务秒数加 3 秒余量，至少 18 秒。
- **搜索**：优先选择可识别的历史词条；没有可用词条时输入“收纳盒”，确认商品结果后再浏览。
- **支付宝相关任务**：蚂蚁庄园、蚂蚁森林、芭芭农场及明确标注支付宝的金豆夺宝等入口，进入后停留 6 秒并返回，不操作页面内的游戏。
- **拍立淘**：进入页面后停留 6 秒，不滑动。
- **任务核对**：标题与按钮必须属于同一行容器；点击前重新核对任务、进度、文案和位置，变化则重新扫描。
- **升级弹窗**：识别关闭文字、无障碍描述、控件 ID 或叉号。关闭不可用时尝试一次返回，并通过明确的淘金币入口恢复赛车页；确认能量可读后继续。

微博、快手、来源不明的签到、购买、付款、充值、分享、邀请、关注等任务会跳过。无法识别的任务需手动完成。

## 运行环境

- Windows 电脑；推荐 Python 3.10 或更新版本。
- Android 手机，已开启并授权 USB 调试或无线调试。
- 淘宝已登录，并能进入 2026 双11活动。

不支持通过 ADB 连接 iPhone。Windows 启动脚本会使用当前文件夹的独立 Python 环境，不修改全局 Python 包或系统代理。

## 开始使用

1. 下载并解压仓库，或执行 `git clone https://github.com/TySchip/taobao-2026-adb.git`。不要直接在压缩包内运行。
2. 双击 `install.cmd`，等待当前目录的 `.venv` 创建及依赖安装完成。
3. 连接并授权手机，双击 `check_device.cmd`，确认设备状态是 `device`。
4. 在手机打开淘宝双11活动的“做任务赚能量 / 体力”列表，处理遮挡页面的弹窗。
5. 双击 `start.cmd`，先选 **1** 核对任务，再选一次 **2** 自动执行。
6. 升级赛车时，收起任务列表，回到显示剩余能量的赛车页，选 **3**。升级过程中的已识别弹窗会自动关闭。

运行期间保持手机解锁，不要同时手动操作。按 **Ctrl+C** 停止。

首次连接时，uiautomator2 会向手机部署并启动控件读取与操作服务；预览模式也需要该服务。

### 无线连接

Android 11 及以上可使用系统“开发者选项 → 无线调试”。手机和电脑需在可互通的局域网中。在系统的配对码页面获取配对端口，主页面获取连接端口，两者通常不同。

在脚本文件夹打开 PowerShell，使用已安装依赖自带的 ADB：

```powershell
# 替换为手机显示的地址和端口；按提示在本机输入配对码。
$adbExe = & .\.venv\Scripts\python.exe -c "from adbutils import adb_path; print(adb_path())"
& $adbExe pair PHONE_IP:PAIR_PORT
& $adbExe connect PHONE_IP:CONNECT_PORT
```

也可使用单独安装的 Android Platform-Tools 执行 `adb pair` / `adb connect`。配对码和手机地址不用写入源码。

### 命令行

```powershell
# 默认仅预览
.\.venv\Scripts\python.exe .\taobao_2026.py

# 自动任务
.\.venv\Scripts\python.exe .\taobao_2026.py --run

# 赛车升级，会消耗活动能量
.\.venv\Scripts\python.exe .\taobao_2026.py --upgrade

# 连接多台设备时，指定 adb devices 显示的设备标识
.\.venv\Scripts\python.exe .\taobao_2026.py --serial PHONE_SERIAL --run
```

若使用单独下载的 ADB，可将其放在 `platform-tools/adb.exe`。启动脚本优先使用它，只影响本次进程；否则由 adbutils 使用可用的 ADB。

## 停止与恢复

- 已识别的验证码、访问限制、登录验证、订单支付页面、未允许的应用、设备断开或熄屏会停止操作。
- 同名、同进度、同操作的任务一轮内只尝试一次；未增加进度时跳过，继续其他任务。任务消失或换名后重新扫描。
- 升级弹窗恢复最多执行四次关闭或导航操作，返回键最多一次；恢复失败、能量无法读取或连续三轮未减少时停止。
- 任务循环最多 60 次，循环开始前检查约 20 分钟的时限；连续四屏没有新任务时结束。赛车升级最多 60 轮，剩余能量不足 10 时结束。

页面识别依赖应用暴露的控件与文字，界面更新、纯图片弹窗或账号差异可能需要适配。后台页面查询有延迟，不能保证即时识别所有验证。

## 测试与日志

仓库提供 **82 项离线测试**，无需连接手机、安装 ADB 或安装控制依赖：

```powershell
python -X utf8 -B -m unittest discover -s tests -v
```

测试覆盖任务筛选、点击前变化、搜索、连续浏览、支付宝与拍立淘短停、升级弹窗恢复，以及验证中止。此前部分浏览和短停流程做过 Android 14 真机单项验证；本次升级弹窗更新仅做离线验证，没有进行完整任务轮次的真机验收。

运行日志保存在 `logs/`，记录任务、点击位置、进度、能量和停止原因。不主动保存完整界面 XML、截图、Cookie、Token 或设备序列号，也不上传日志。分享问题日志前请自行检查是否含有不希望公开的任务信息。
